# 🎬 CineRank — Movie Ratings Explorer (IMDb / Netflix)

**HTML5 · CSS3 · JavaScript · Data Structures & Algorithms**

A fast, responsive web app to search, filter and rank 3,000+ movies. The UI is hand-written
(no frameworks), and every heavy operation is powered by a classic data structure or algorithm.

## ▶ How to run
No install, no build step.

1. Unzip the folder.
2. Double-click **`index.html`** (or serve it: `python3 -m http.server` → http://localhost:8000).

> Google Fonts load from the internet; offline it falls back to system fonts automatically.

## ✨ Features
- Live search with autocomplete (press **/** to focus), keyboard navigation (↑ ↓ Enter Esc)
- Filter by genre (match Any / All), rating, release year, votes, platform, language
- Sort by rating, weighted "top picks", popularity, year, runtime or title — one click to reverse
- Grid / list view, infinite scroll, rating histogram, top-5 picks for the current view
- Movie details modal with rank, weighted score, "Find similar" and a persistent **watchlist** (localStorage)
- Dark / light theme, scroll progress bar, animated counters, card hover effects, `prefers-reduced-motion` support
- Fully responsive (mobile filter drawer), accessible (labels, focus rings, ARIA, focus trap in modals)
- **Benchmark** button: measures the indexed approach vs. a naive one on *your* machine
- **Import CSV**: load the real Kaggle IMDb/Netflix file (see below)

## 🧠 DSA used (`js/algorithms.js`)
| Problem | Technique | Naive baseline |
|---|---|---|
| Sort by any field | Bottom-up **merge sort** O(n log n), stable, run once per key at load | `Array.sort` on every change |
| Re-sort / reverse | Pre-sorted index arrays → one O(n) pass (reverse = iterate backwards) | re-sort O(n log n) |
| Title search | **Inverted index** (word → movie ids) + **binary search** on the sorted word list for prefix matches; multi-word = AND (intersection) | scan every title |
| Autocomplete | Binary search (`lowerBound`) over sorted titles → O(log n + k) | linear scan |
| Genre filter | **Bitmask** per movie, test with one `&` | array `includes` |
| Top picks | **Min-heap** of size k → O(n log k) | sort everything |
| Ranking | IMDb weighted rating `(v/(v+m))·R + (m/(v+m))·C` | raw rating |

## 📂 Using the real Kaggle dataset
The app ships with a generated **sample** dataset (3,200 records, `js/data.js`) so it works instantly.
To use real data, click **Import CSV** and pick a file such as the Kaggle
"IMDB Top 1000" / "Netflix Movies and TV Shows" CSV. Columns are detected automatically
(`title/Series_Title`, `year/Released_Year/release_year`, `genre/listed_in`, `rating/IMDB_Rating/imdb_score`,
`votes/No_of_Votes`, `runtime/duration`, `language`, `platform`). Rows without a title, year or numeric rating are skipped.

To bundle your own data permanently, replace `window.MOVIES_DATA` in `js/data.js` with rows of the form
`[id, title, year, "Genre|Genre", rating, votes, runtime, language, platform]`.

